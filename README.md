# AI Knowledge Assistant

A real-time AI-powered assistant built using Node.js, Express, OpenRouter AI, and Tavily Search API.
This project can answer both general AI questions and real-time queries such as news, weather, sports, trends, and more.

---

## Features

* Real-time AI responses
* Web search integration using Tavily API
* AI responses powered by OpenRouter
* Clean frontend UI
* Fast backend using Express.js
* REST API integration
* Real-time information retrieval
* Easy deployment

---

## Installation

Clone the repository:

```bash id="7h8x2s"
git clone https://github.com/Jaswanth7373/AI-PROJECT.git
```

Go to project folder:

```bash id="jlwm8a"
cd AI-PROJECT
```

Install dependencies:

```bash id="jlwm8b"
npm install
```

---

## Environment Variables

Create a `.env` file in the root directory:

```env id="jlwm8c"
OPENROUTER_API_KEY=your_openrouter_api_key
TAVILY_API_KEY=your_tavily_api_key
```

---

## Running the Project

Start the server:

```bash id="jlwm8d"
node server.js
```

Server runs at:

```txt id="jlwm8e"
http://localhost:3000
```
